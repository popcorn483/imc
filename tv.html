Set up this foyer TV

This TV will play exactly what the manager's computer has set: trailers, showtimes, deals and adverts, in step with the other foyer TVs. Nothing needs changing on this PC.

Make it start by itself when the PC is switched on
  1. Click Install as an app above (or in Chrome: ⋮ menu › Cast, save and share › Install page as app). An “IMC Foyer TV” icon appears on the desktop.
  2. Press the Windows key + R, type shell:startup and press Enter. A folder opens.
  3. Drag the IMC Foyer TV icon from the desktop into that folder, holding the right mouse button, and choose Create shortcut here.
  4. That's it: when the PC starts, the TV starts. Click the screen once for sound after a restart (browsers need one click).

To change this later, open this page with ?setup at the end of the address.
